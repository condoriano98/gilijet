## What went wrong on the way (kept as lessons)

| What | Cause | Fix |
|---|---|---|
| 39 failures in one stage 1 run | the run reused a leftover dev server whose environment lacked three variables | check port 3000 before a run |
| The owner could not open From and To, and saw two different port lists and "no legs" | the owner's `pnpm dev` (Supabase staging data) and a server of mine (local database) were both being opened on port 3000 | the config never reuses a server on port 3000; stop what you start |
| The consent banner covers the To field on a first visit (bug B14) | every spec had a saved consent choice, so no test ever saw the banner | no default consent cookie; `CONT-035` records B14 as a known bug |
| 97 skipped in one run | the runner process still held live keys from `.env` (loaded by Prisma), and the booking specs refuse to run with live keys | the config blanks the outbound variables in the runner too |
